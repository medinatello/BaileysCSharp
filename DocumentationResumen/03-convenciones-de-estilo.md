## Títulos y slugs
- H1 para el nombre del archivo, H2 para secciones principales.
- Slugs en minúsculas, sin acentos y espacios reemplazados por guiones.
- Evitar el uso de emojis en títulos y texto.

## Tablas y código
- Las tablas deben tener encabezado y contenido alineado.
- Los bloques de código usan triple tilde con lenguaje cuando aplique.

## Diagramas Mermaid
- Cada diagrama debe probarse sintácticamente.
- Usar tipos `flowchart` o `sequence` según corresponda.
