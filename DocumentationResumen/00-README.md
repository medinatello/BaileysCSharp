## Propósito
Este directorio centraliza y deduplica la documentación generada por las carpetas `DocumentationCodex`, `DocumentationJules` y `DocumentationCopilot`.
Su objetivo es ofrecer una vista única y trazable sin alterar los orígenes.

## Navegación
- Consulte `01-indice-tematico.md` para un índice global.
- Cada archivo incluye anclas estables y una sección de **Proveniencia** con enlaces relativos a los archivos fuente.
- El mapa completo de correspondencias está en `02-mapa-origenes.md`.

## Metodología
La unificación agrupa contenidos por temas, fusiona secciones equivalentes y conserva matices únicos.
Cuando existieron afirmaciones contradictorias se documentaron en `98-conflictos-abiertos.md`.

## Notas
- Las carpetas de origen permanecen intactas; modifique únicamente este resumen.
- Debido a tiempo limitado, algunos temas contienen `TODO` pendientes para revisión futura.
